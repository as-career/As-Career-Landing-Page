# Apex Career

A modern Next.js 15 website for a career consultancy and job placement training institute, built with the App Router, TypeScript, Tailwind CSS, Framer Motion, and shadcn/ui-inspired components.

## Features

- Responsive marketing website for home, courses, placements, tie-ups, about, and contact
- Professional navy-and-gold design system with premium UI patterns
- Typed content model for courses, placements, leaders, reviews, and partners
- SEO metadata, Open Graph tags, structured data, robots.txt, and sitemap
- Contact form UI with validation using React Hook Form and Zod

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Build

```bash
npm run build
```

## Notes

The contact form is ready for integration with an email service such as Resend or a server-side form endpoint.
